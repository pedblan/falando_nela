# Notebooks legados — consulta

Os notebooks Jupyter e Google Colab deste repositório são preservados como
fontes históricas de decisões, parâmetros e experimentos. Desde a limpeza R09,
eles não são entrypoints operacionais, não definem o caminho oficial de dados e
não devem ser executados contra o Drive ou fontes parlamentares sem uma tarefa
própria e revisão de seus contratos.

O caminho local oficial usa `FALANDO_NELA_DATA_ROOT` apontando para
`data_samples/`. Novas interfaces de caderno serão implementadas em Marimo por
recortes verticais. Código e documentação da última linha Colab permanecem
recuperáveis pela tag `legacy-colab-final`.

As subpastas mantêm nomes e arquivos originais para consulta e proveniência.
Referências a `/content/drive`, montagem do Drive ou comandos antigos devem ser
lidas como história, não como instruções atuais.
